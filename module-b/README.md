# B Modulu — Logların Emalı və Optimallaşdırılması

Bu modulun məqsədi sintetik təhlükəsizlik loglarını Vector vasitəsilə emal etmək və OpenSearch sisteminə ötürməzdən əvvəl optimallaşdırmaqdır.

### Əsas məqsədlər
- Log sahələrinin standartlaşdırılması
- Həssas məlumatların maskalanması
- Lazımsız sahə və hadisələrin filtrlənməsi
- Logların mənbələrə görə yönləndirilməsi
- Emal olunmuş logların OpenSearch-ə ötürülməsi
- Təhlükəsizlik aşkarlama qaydalarının qorunmasının yoxlanılması

### Log mənbələri
- Linux autentifikasiya logları
- Veb-server logları
- Firewall logları

### İstifadə olunan texnologiyalar
- Vector
- OpenSearch
- AWS EC2
