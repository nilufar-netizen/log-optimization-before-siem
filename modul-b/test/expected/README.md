
# Expected Output Logs

Bu qovluqda Vector tərəfindən emal edildikdən sonra loglar üçün gözlənilən nəticələr saxlanılacaq.

### Məqsəd
Bu fayllar emal olunmuş logların düzgünlüyünü yoxlamaq üçün istifadə ediləcək.

### Yoxlanılacaq meyarlar
- Həssas məlumatların maskalanması
- Vacib log sahələrinin qorunması
- Log formatının standartlaşdırılması
- Lazımsız sahələrin razılaşdırılmış qaydalara əsasən filtrlənməsi
- İlkin və emal olunmuş logların müqayisəsi

Gözlənilən nəticə faylları real test nümunələri əsasında əlavə ediləcək.
